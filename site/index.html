software-factory

Label an issue factory and stations on GitHub Actions take it from triage to a reviewed, tested pull request. It runs on a Claude subscription, with no API bill.

  1. 1TriageReads the issue and the code, writes acceptance criteria, or asks what's missing.
  2. 2ImplementMakes the smallest change that meets the criteria and opens a draft pull request.
  3. 3ReviewA different model checks the diff against the criteria. Up to two revision rounds.
  4. 4EvidenceRuns the checks and attaches before and after screenshots and a video.
  5. 5GateWaits for CI, fixes red checks, and merges on green where that's allowed.
Source: github.com/PranayHaldiya/software-factory
